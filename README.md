# 互动地图

真实地理互动地图。页面使用 Leaflet 与国土地理院标准地图，地点采用真实坐标和故事定位结合，路线仅用于叙事展示。

## 本地打开

建议使用 Node.js 24；开发和构建至少需要 Node.js 20.19。

```powershell
npm start
```

随后打开 <http://localhost:8765/>。

开发模式支持自动刷新：

```powershell
npm install
npm run dev
```

## 构建

```powershell
npm ci
npm run build
```

静态网站会生成在 `dist/` 目录中。

## 上传 GitHub

1. 在 GitHub 新建一个空仓库。
2. 将本项目全部文件上传至仓库根目录。
3. 在仓库的 **Settings → Pages → Build and deployment** 中选择 **GitHub Actions**。
4. 推送至 `main` 或 `master` 分支后，内置工作流会自动构建并发布网站。

## 修改内容

- `journey-data.js`：地点、坐标、剧情和路线。
- `index.html`：页面标题和固定文字。
- `styles.css`：颜色、字体、侧栏、标记和弹窗。
- `app.js`：Leaflet 地图与进度交互。

## 进度操作

- 双圆实心标记：两人已经到达。
- 带橙色脉冲的双圆标记：当前所在地。
- 空心星标：计划地点。
- “×”“桥”“休”小标记：道路中断、经过桥梁与临时休息处，不计入行程进度。
- 点击计划地点后，可以标记两人抵达。
- 进度保存在当前浏览器的 `localStorage` 中。
- “恢复故事当前进度”会回到“大井川东岸”（UNIT 05）。

## 当前坐标说明

- 石蕗高中采用其现实参照“爱知县立时习馆高校”的坐标。
- 家庭餐厅和滨名湖西岸休息点属于故事定位。
- 滨名湖 Garden Park 展望塔、ACT CITY 滨松与“道之驿挂川”采用设施真实坐标。
- UNIT 05 的国道断桥西岸与维护桥东岸采用故事定位；现实道路与桥梁没有发生剧情中的坍塌。
- 下一站“静冈市区”暂以静冈站周边作为计划定位。
- 白色残骸只标示故事中确认的大致海域，不能视为现实地点。
- 折线路线依据道路数据绘制，但不可作为导航使用。
